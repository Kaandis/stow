Questions

How do I choose which icons hide?

Hold ⌘ and drag an icon in the menu bar. Everything left of Stow’s thin divider tucks away; everything right of its arrow stays. macOS remembers the order.

Does it work on macOS 27?

Yes. macOS 27 draws the menu bar as one piece and adds its own overflow arrow at the edge of the icons. Stow’s tucked-away icons go there, so they’re still a click away from the system’s arrow too.

Why doesn’t it have a separate bar for hidden icons, like Ice?

On macOS 27 the menu bar no longer exposes each icon on its own, so a second bar would rely on fragile tricks that break with updates. Stow sticks to what macOS supports.

What permissions does Stow need?

None. It only adds its own small items to the menu bar: an arrow and a divider (two if you use Always Hidden).

macOS says it can’t be opened.

Builds aren’t notarized yet. Right-click Stow and choose Open, or run xattr -dr com.apple.quarantine /Applications/Stow.app.
